
# Student Grade Calculator

A simple Python project to calculate student total marks, percentage, and grade.

## Features

- Enter student name
- Enter marks for 3 subjects
- Calculate total marks
- Calculate percentage
- Display grade

## Technologies Used

- Python

## How to Run

1. Download the `grade_calculator.py` file.
2. Open it using Python.
3. Enter the student name and marks.
4. The program will display the total, percentage, and grade.

## Grade System

- 90 and above → A+
- 80–89 → A
- 70–79 → B
- 60–69 → C
- 50–59 → D
- Below 50 → F
